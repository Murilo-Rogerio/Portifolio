## 👁️ Visão Geral

O objetivo principal deste projeto é apresentar meu perfil profissional e técnico de forma clara, interativa e elegante, sem a necessidade de dependências pesadas ou frameworks complexos.

- **Design:** Bento Grid escuro (*Dark Mode native*) com suporte a acentos em gradiente e efeito *glassmorphism*.
- **Acessibilidade:** Marcação HTML5 semântica e atributos ARIA para melhor navegação por leitores de tela.
- **Performance:** Carregamento ultra-rápido, otimizado sem bibliotecas de terceiros além de fontes web.

---

## ✨ Funcionalidades

- 📊 **Bento Grid Layout:** Organização modular para perfis, experiências, habilidades e projetos.
- ⏱️ **Barra de Progresso de Leitura:** Indicador no topo acompanhando o rolamento da página.
- 📋 **Atalhos Rápidos:** Botões para cópia instantânea de dados de contato (E-mail, LinkedIn, GitHub).
- 📱 **Totalmente Responsivo:** Adaptação fluida para dispositivos móveis, tablets e desktops.
- 🎨 **Efeitos Visuais Sutis:** Fundo ambiente em gradiente e transições suaves de interatividade.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica rigorosa.
- **CSS3:** Variáveis nativas (`:root`), Flexbox, CSS Grid, `backdrop-filter` e animações leves.
- **JavaScript (Vanilla):** Lógica simples e direta sem frameworks.
- **Typography:** Fonts *Outfit* e *JetBrains Mono* via Google Fonts.
